# ساختار پوشه‌بندی پادکست کتاب‌ها (`public/podcasts/`)

برای اینکه با اضافه شدن کتاب‌های جدید در آینده، فایل‌های صوتی فصل‌های کتاب‌های مختلف با هم تداخل پیدا نکنند، هر کتاب پوشه اختصاصی خود را بر اساس شناسه (Slug) کتاب دارد:

```text
public/podcasts/
├── from-day-zero-to-zero-day/   <-- پوشه اختصاصی کتاب «از روز صفر تا روز صفر»
│   ├── ch-0.m4a
│   ├── ch-1.m4a
│   ├── ...
│   └── ch-10.m4a
│
└── <next-book-slug>/            <-- پوشه اختصاصی کتاب‌های بعدی
    ├── ch-1.m4a
    ├── ch-2.m4a
    └── ...
```

> **نکته:** تمام نسخه‌های زبانی یک کتاب (مثلاً نسخه انگلیسی `from-day-zero-to-zero-day` و نسخه‌های فارسی `from-day-zero-to-zero-day-fa`) به‌صورت هوشمند از همان پوشه واحد `public/podcasts/from-day-zero-to-zero-day/` استفاده می‌کنند تا نیاز به کپی کردن تکراری فایل‌های حجیم `.m4a` نباشد.
