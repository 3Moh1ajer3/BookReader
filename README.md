# کتاب‌خوان هوشمند و جامع آسیب‌پذیری‌های امنیتی (Smart Security Reader)

این پروژه یک نرم‌افزار کتاب‌خوان مدرن، آفلاین‌محور و تعاملی است که به صورت تخصصی برای مطالعه کتاب‌های مهندسی نرم‌افزار، امنیت سایبری و به خصوص کتاب مرجع **«از روز صفر تا صفر روز: راهنمای عملی پژوهش آسیب‌پذیری» (From Day Zero to Zero Day by Eugene Lim / Spaceraccoon)** به دو زبان **انگلیسی** و **ترجمه کامل فارسی** طراحی شده است.

---

## ۱. ویژگی‌های کلیدی (Key Features)

- 📖 **کتابخانه دوزبانه همگام (Dual-Language Sync):** مطالعه هر دو نسخه اصلی انگلیسی و ترجمه کامل فارسی با قابلیت سوییچ آنی میان دو زبان در همان فصل جاری.
- 🎨 **موتور رندرر هوشمند (Smart RTL/LTR):** چینش خودکار راست‌به‌چپ متون فارسی همراه با حفظ چپ‌به‌راست و استایل اختصاصی برای صدها بلوک کد اسمبلی، C، پایتون، رگولار اکسپرشن‌ها و دستورات شل.
- ⚡ **دیکشنری و تحلیلگر معنایی هوشمند:** انتخاب هر کلمه یا جمله برای دریافت ترجمه فوری، تلفظ صوتی (TTS)، مترادف‌ها و توضیح مفهومی اصطلاحات با پشتیبانی از Google Gemini API.
- 🖍️ **هایلایت و یادداشت‌برداری چندرنگ:** امکان علامت‌گذاری پاراگراف‌ها با رنگ‌های مختلف و ذخیره در کشوی یادداشت‌ها.
- 🗃️ **جعبه لغات (Vocabulary Flashcards):** ذخیره کلمات جدید و مرور آن‌ها به همراه معانی تخصصی.
- 📥 **استخراج کتب و PDF (In-Browser PDF Importer):** تبدیل کتاب‌های PDF به فصول استاندارد مارک‌داون بدون نیاز به سرور جانبی با استفاده از `pdfjs-dist`.
- 💾 **خروجی تک‌فایلی مستقل (Offline HTML Exporter):** دانلود کل کتاب یا فصول در قالب یک فایل HTML تک و کاملاً مستقل که در تمام سیستم‌عامل‌ها و گوشی‌ها بدون نیاز به نصب یا اینترنت باز می‌شود.
- 🌓 **طراحی چشم‌نواز با ۳ تم بصری:** حالت روز (Light)، حالت شب (Dark) و حالت مطالعه آرامش‌بخش (Sepia/کرم) با امکان تغییر اندازه قلم.

## ۲. مشخصات فنی و استک (Tech Stack)

| بخش | تکنولوژی | توضیحات |
| :--- | :--- | :--- |
| **Framework** | Next.js 15+ (App Router) | فریمورک مدرن فول‌استک بر پایه React 19 |
| **Language** | TypeScript 5.9 | تایپ‌سیف کامل برای کل ساختار داده‌ها و مدل‌ها |
| **Styling** | Tailwind CSS v4 | استایل‌دهی سریع و مدرن همراه با `@tailwindcss/typography` |
| **Icons** | Lucide React | کتابخانه یکپارچه آیکون‌ها |
| **Animations** | Motion (`motion/react`) | انیمیشن‌های نرم رابط کاربری و منوها |
| **AI Integration** | Google GenAI SDK (`@google/genai`) | مدل‌های هوشمند Gemini برای تحلیل و ترجمه عمیق اصطلاحات |
| **PDF Extraction**| `pdfjs-dist` | پردازش کلاینت‌ساید اسناد PDF |
| **Persistence** | Browser `localStorage` | ماندگاری کامل اطلاعات و تنظیمات بدون نیاز به دیتابیس خارجی |

## ۴. نحوه نصب و راه‌اندازی در محیط محلی (Local Development)

### پیش‌نیازها
- نصب **Node.js** (نسخه ۱۸ یا بالاتر، توصیه می‌شود v20 یا v22)
- مدیر بسته `npm` یا `bun` یا `pnpm`

### مراحل راه‌اندازی

۱. **کلون کردن مخزن یا ورود به پوشه:**
\`\`\`bash
cd project-directory
\`\`\`

۲. **نصب پکیج‌ها:**
\`\`\`bash
npm install
\`\`\`

۳. **تنظیم متغیرهای محیطی (اختیاری):**
یک فایل `.env.local` ایجاد کنید و در صورت تمایل به فعال‌سازی هوش مصنوعی Gemini، کلید خود را اضافه کنید:
\`\`\`env
GEMINI_API_KEY="AIzaSy..."
\`\`\`
*(نکته: در صورت نبود کلید، برنامه بدون مشکل کار کرده و از ترنسلیتور و دیکشنری آفلاین درونی استفاده خواهد کرد).*

۴. **اجرای سرور توسعه:**
\`\`\`bash
npm run dev
\`\`\`
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` بروید.

۵. **کامپایل و بیلد نسخه پروداکشن:**
\`\`\`bash
npm run build
npm run start
\`\`\`

## ۵. راهنمای کار با ابزارهای Agentic (Cursor / Claude Code / Devin / Windsurf)
اگر می‌خواهید پروژه‌تان را با ابزارهای برنامه‌نویسی ایجنتی (مانند Cursor، Claude Code، Windsurf، Aider و غیره) توسعه دهید:
- فایل `AGENTS.md` در ریشه پروژه قرار داده شده است که تمام معماری، قواعد اینترفیس‌ها و محدودیت‌ها را به مدل هوش مصنوعی آموزش می‌دهد.
- برای افزودن کتاب یا فصل جدید، کافیست از ساختار `types/reader.ts` پیروی کنید و در `data/sampleBooks.ts` آن را ثبت کنید.
