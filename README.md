# پورتال امنیت سایبری رهام و کتاب‌خوان هوشمند دوزبانه (Roham Security & Reader)

این پروژه یک وب‌اپلیکیشن جامع، مدرن و دومنظوره است که شامل **پورتال تخصصی امنیت سایبری رهام** و **کتاب‌خوان هوشمند متون فنی و مهندسی معکوس** می‌باشد. معماری پروژه برای بیشترین سادگی، سرعت و پایداری به صورت **فرانت‌اند Next.js استاتیک + بک‌اند خالص PHP و دیتابیس MySQL روی سی‌پنل (cPanel)** طراحی شده است.

---

## ۱. ویژگی‌های کلیدی سامانه

### ۱. پورتال امنیت سایبری و تحقیقات رهام
- 🛡️ **تحقیقات آنتی‌استیلر (Anti-Stealer Labs):** کالبدشکافی بدافزارهای سرقت اطلاعات، تکنیک‌های دور زدن App-Bound Encryption و راهکارهای دفاعی.
- 📡 **رادار بلادرنگ تهدیدات (Threat Radar):** رصد و انتشار هشدارهای امنیتی بحرانی، آسیب‌پذیری‌های روز صفر و شاخص‌های آلودگی (IoC).
- 📝 **وبلاگ و مقالات عمیق (Technical Deep-Dive):** مقالات پژوهشی مهندسی معکوس همراه با قطعه‌کدهای تفکیک‌شده.
- 🎓 **دوره‌های آموزشی تخصصی و پذیرش سازمانی:** ثبت‌نام آنلاین دوره‌ها و فرم‌های درخواست مشاوره و ارزیابی ریسک با کد پیگیری اختصاصی.
- ⚙️ **پنل مدیریت یکپارچه (Admin Panel):** مدیریت کاربران، ارتقای نقش‌ها، بررسی درخواست‌ها، تنظیمات سامانه و پایش دیتابیس.

### ۲. کتاب‌خوان هوشمند مهندسی (Technical Reader)
- 📖 **کتابخانه دوزبانه همگام:** نسخه انگلیسی و ترجمه کامل فارسی کتاب مرجع *«From Day Zero to Zero Day»* با سوییچ آنی زبان در هر فصل.
- 🎨 **موتور رندر هوشمند RTL/LTR:** حفظ ساختار چپ‌به‌راست و فونت مونو در تمام بلوک‌های کد اسمبلی، C، پایتون و جداول فنی همراه با راست‌به‌چپ متون فارسی.
- ⚡ **دیکشنری و ترجمه تخصصی اصطلاحات:** ترجمه کلمات و اصطلاحات مهندسی با دیکشنری فنی درونی و اندپوینت `/api/translate.php`.
- 🎧 **پادکست صوتی فصول:** پلیر صوتی اختصاصی برای شنیدن تحلیل صوتی فصل‌های کتاب.
- 🖍️ **هایلایت و همگام‌سازی ابری:** ذخیره هایلایت‌ها و واژگان بر روی حساب کاربری در دیتابیس MySQL هاست.

## ۲. مشخصات فنی و معماری سامانه

| بخش | تکنولوژی | توضیحات |
| :--- | :--- | :--- |
| **Frontend Framework** | Next.js 15+ (React 19) | خروجی استاتیک بهینه (`output: 'export'`) |
| **Styling** | Tailwind CSS v4 | استایل‌دهی مدرن با فونت‌های استاندارد وزیرمتن و جت‌برینز مونو |
| **Icons** | Lucide React | کتابخانه یکپارچه و بهینه آیکون‌ها |
| **Animations** | Motion (`motion/react`) | انیمیشن‌های روان و سبک رابط کاربری |
| **Backend API** | PHP 8.x (`public/api/*.php`) | اندپوینت‌های سبک و امن RESTful |
| **Database** | MySQL (PDO) | پایگاه‌داده ساختاریافته روی هاست سی‌پنل (`corpel_roham`) |
| **Authentication** | Bcrypt + HMAC-SHA256 | رمزنگاری امن پسوردها و توکن‌های نشست ورود |

## ۴. نحوه توسعه محلی (Development)

۱. **نصب وابستگی‌ها:**
```bash
npm install
```

۲. **اجرای سرور توسعه:**
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

۳. **بررسی صحت کدها:**
```bash
npm run lint
```

۴. **تولید خروجی نهایی استاتیک:**
```bash
npm run build
```
پوشه `out/` آماده آپلود در `public_html` هاست سی‌پنل ایجاد می‌شود.

## ۵. نحوه استقرار روی هاست سی‌پنل (cPanel Deployment)

1. خروجی بیلد یا فایل زیپ آماده **`public/roham-cpanel-deploy.zip`** را در پوشه `public_html` هاست آپلود و آنزیپ (Extract) کنید.
2. مشخصات دیتابیس MySQL هاست خود را در صورت نیاز در فایل `api/config.php` تنظیم نمایید:
   ```php
   $DB_HOST = "localhost";
   $DB_NAME = 'corpel_roham';
   $DB_USER = 'corpel_roham_12_db';
   $DB_PASS = '...';
   ```
3. جداول دیتابیس در اولین فراخوانی توسط `api/db.php` به‌صورت خودکار ایجاد می‌شوند (همچنین فایل `api/schema.sql` برای ایمپورت دستی از phpMyAdmin در دسترس است).
4. با مشخصات پیش‌فرض مدیر ارشد وارد پنل مدیریت شوید:
   - **نام کاربری:** `admin`
   - **رمز عبور:** `Admin@1234`
